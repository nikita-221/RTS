📖 Overview

AI Resume Analyzer is a smart web application developed using Python that helps users upload and analyze resumes intelligently. The system extracts resume data, calculates resume scores, stores uploaded files, and provides resume management features through an interactive dashboard.

This project is designed to simplify resume screening and provide AI-based insights for better recruitment and resume evaluation.
