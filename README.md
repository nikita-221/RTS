# 🚀 Resume Tracking System (RTS)

A modern web-based Resume Tracking System designed to streamline the recruitment process by providing separate dashboards for candidates and administrators. The platform enables efficient resume management, application tracking, and record maintenance through a secure and user-friendly interface.

## ✨ Key Features

### 👤 User Portal

* Secure User Registration & Login
* Resume Upload & Management
* Application Status Tracking
* Profile Management
* Application History

### 🛠️ Admin Portal

* Secure Admin Authentication
* Candidate Management
* Resume Review & Monitoring
* Application Tracking
* Recruitment History Management
* Centralized Dashboard

## 💻 Technology Stack

* **Backend:** Python, Flask
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** SQLite
* **Version Control:** Git & GitHub

## 🎯 Project Highlights

* Separate Admin and User Dashboards
* Secure Authentication System

* Database-Driven Architecture
